# ADR-003 自腹では始めず、春シーズン前の無料クレジットを待つ

- 状態: 決定（2026-11-17、持ち主が承認）
- 根拠: クラウド側の Claude との 2026-11-17 の検討。参加フォームの表示（下記）

## 決めたこと

- いまは OpenRouter に入金しない。`OPENROUTER_API_KEY` は登録しない
- Metaculus のアカウントとボットは作っておき、`METACULUS_TOKEN` だけ登録する
- 2027年1月開始の春シーズンの前に、参加フォームで無料クレジットを申請する。通ったら、届いた OpenRouter のキーで試運転（`KICKOFF.md` の手順2〜）に進む
- `KICKOFF.md` の作業は、手順1（鍵の確認）で止めたままにする

## 理由

- 参加フォームに「Credit requests are now closed for the Fall season. We plan to reopen applications a few weeks before the next season starts.」と表示されていた（2026-11-17）
- 今のボット（見本そのまま、forecasting-tools 0.3.5 で gpt-4o 系）では、秋シーズンの残りで賞金に届く見込みは低い。自腹で払って得るものが小さい
- 持ち主はカードでの支払いに慎重。無料クレジットが通れば、自腹ゼロで始められる

## 捨てた案

- 10ドルだけ入金して試運転: 費用と動作を先に知れるが、急ぐ理由がない
- やめる: 実験としての価値は残っているので、まだ捨てない

## 見直すとき

- クレジットの申請が再開されたとき（申請する）
- 申請が通らなかったとき（自腹で始めるか、やめるかを持ち主が決める）
