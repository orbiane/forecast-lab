# ADR-001 Metaculus FutureEval に、見本ボットそのままの基準版で参加する

- 状態: 決定（2026-11-17、持ち主が承認）。「動かす場所（非公開）」「実行頻度（毎時）」は ADR-002 で置き換え
- 根拠: クラウド側の Claude との 2026-11-16〜17 の検討（`docs/sources.md`）

## 決めたこと

| 項目 | 決定 |
|---|---|
| 出る大会 | Metaculus FutureEval のボット大会（シーズン大会と MiniBench） |
| 人の関与 | 人間は途中で手を出さない（大会ルール） |
| 最初のボット | Metaculus 公式の見本（metac-bot-template）を、中身を変えずに使う |
| 動かす場所 | GitHub Actions（非公開リポジトリ `orbiane/forecast-lab`） |
| 実行頻度 | 毎時1回（見本は20分おき） |
| 安全スイッチ | リポジトリ変数 `BOT_ENABLED` が `true` のときだけ定時実行 |
| Metaculus Cup | 定時実行を止める（ボットは賞金対象外。変数 `CUP_ENABLED` で再開できる） |
| 予定 | 今から MiniBench で腕試し → 2027年1月開始の春シーズンが本番 |

## 理由

- 基準版を先に動かすと、改良の効果を点数で比べられる。測らずに改良すると、良くなったかどうか分からない
- 見本ボットは過去の大会で上位10位に入ったことがある（2025年2月の告知。今の強さは未確認）
- 秋シーズンの残りは1か月ほどで得点は小さい。MiniBench は2週間ごとに結果が出るので、仕組みの確認に向く
- 毎時にしたのは、非公開リポジトリの Actions の無料枠（月2,000分、他の非公開リポジトリと合算）に収めるため。20分おきだと、1回1分としても月約2,160分になり、枠を超える

## 捨てた案

- 予測市場（Polymarket など）: 日本からは利用が制限されていて、賭博罪のおそれがある
- 日本国内の大会（AtCoder、SIGNATE）: AI の自律参加が禁止されているか、賞金が上位だけに偏った単発勝負
- 最初から自作の強いボット: 基準がないと改良を測れないため、後回し

## 保留

- **公開か非公開か**: 公開にすると Actions が無制限になり、頻度を20分おきに戻せる。オープンソースのボットはクレジットが約2倍になる（要約経由の情報）。失うのは、プロンプトの工夫を他人に見られることくらい。持ち主が決める
- **費用の上限**: 1か月あたりの LLM 費用の上限。最初の1週間の実測を見て決める
- **改良の方針**: モデルの組み合わせ、調査の手段（AskNews など）。MiniBench の結果が1回分出てから `NEXT.md` で計画する

## 見直すとき

- MiniBench で、Metaculus 運営の基準ボット（metac-bot）より下位が続いたとき
- 月の費用が上限を超えそうなとき
- 春シーズンの開始時（大会の切り替えでパッケージの更新が要るか確かめる）
