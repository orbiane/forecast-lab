# 分かっている事実と確認状態

確認状態の意味:

- **公式**: 公式ページの記述で確かめた（検索結果の抜粋を含む）
- **観察（要約経由）**: 要約を返す道具越しに見た。生のページは見ていない
- **生データで確認**: ファイルやコマンドの出力を直接見た
- **推測**: 計算や見立て。実測で置き換える
- **要確認**: まだ確かめていない
